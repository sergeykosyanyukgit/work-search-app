# Windows-сборка и поставка

Определи требуемый результат: JS-сборка (`build`), каталог приложения (`pack`) или установщик (`dist`). Выпускай только запрошенный артефакт. Прочитай `package.json`, `electron-builder.yml`, `electron.vite.config.ts`, `scripts/installer.nsh` и `scripts/smoke-packaged.mjs`.

## До сборки

Сверь Node и закрепленный pnpm по package.json. Установку зависимостей и изменение lockfile отделяй от пересборки SQLite; второй lockfile не нужен. Учти текущий ABI и завершение тестов других агентов по [AGENTS.md](../../../AGENTS.md).

Проверь состав `extraResources`: Whisper и VC++ runtime, их происхождение, SHA256/подпись и согласованность setup-скриптов. `setup:runtime` только скачивает ресурс установщика; установка runtime происходит другим действием. Пользовательская Whisper-модель не становится частью пакета автоматически.

Если поручено изменение версии, найди ее реальные объявления через поиск по старой версии: package.json, CLI clientInfo, тексты/скрипты приемки. Исторические benchmark-отчеты не переписывай на новую версию. Для smoke проверь, какой executable и какой каталог ресурсов он фактически использует.

## Собери и проверь

- `pnpm build` проверяет TypeScript и собирает JS, но не доказывает native совместимость.
- `pnpm run pack` собирает Windows x64 каталог и подготавливает SQLite для Electron; `pnpm test:packaged` проверяет его в отдельном профиле.
- `pnpm run dist` создает NSIS. Сохрани `asarUnpack` для native .node и ресурсы по конфигурации builder.

Не выполняй ABI-пересборки одновременно с Vitest/Electron серией. Если после упаковки нужны Node-тесты хранения, верни Node ABI явно и сообщи это. Свежий installer и старый win-unpacked не являются взаимозаменяемыми доказательствами.

В отчете укажи новый артефакт, фактическую версию, размер/SHA256 установщика при его создании, результаты smoke и оставшееся состояние ABI. Различай упаковку, запуск каталога, установку на чистой Windows и публикацию. Подпись кода и автообновление должны подтверждаться настроенной реализацией, а не наличием NSIS.

Для установки в рабочую систему, публикации или изменения внешнего manager выполняй только уже порученный объем. Сборка локального пакета сама по себе не запускает эти операции.
