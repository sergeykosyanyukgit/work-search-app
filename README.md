# Work Search

Помощник для собеседований на Windows 11 x64. Electron + React + TypeScript; локальный Whisper распознает микрофон и системный звук раздельно, а ответы приходят через локальный установленный Codex или облачный codex-manager по WebSocket.

Приложение показывает текстовую подсказку в окне поверх звонка. Вы записываете вопрос или вводите его вручную, а AI учитывает ваше резюме, вакансию и предыдущие вопросы интервью. Запись начинается только по вашему действию.

## Возможности

| Функция | Что доступно |
| --- | --- |
| Вопрос голосом | Микрофон, системный звук или оба источника; уровни звука, таймер, остановка кнопкой или сочетанием клавиш |
| Распознавание | Локальный Whisper Small на CPU; русский, английский и автоопределение; расшифровка по источникам с временными метками |
| Вопрос текстом | Ручной ввод без установленной STT-модели |
| AI-подсказка | Обновление ответа по мере генерации, Markdown и код, краткий или подробный стиль |
| Контекст | Резюме, вакансия и пожелания; настройки контекста фиксируются на интервью |
| Очередь | До трёх незавершённых вопросов по порядку; распознавание следующего может идти одновременно с текущим ответом |
| Исправления | Отмена обработки и отправка новой версии вопроса с сохранением предыдущей |
| История | Создание, завершение, продолжение и удаление интервью; поиск по названию |
| Оверлей | Окно поверх приложений, пропуск кликов, прозрачность, размер текста, три темы, трей и горячие клавиши |
| Диагностика | Статусы подключения и обработки, время до первого текста и полного ответа, восстановление незавершённых AI-запросов |

В записи одного вопроса действует ограничение 2 минуты. Частичный захват требует проверки текста перед отправкой; пустая речь не отправляется в AI. Приложение не подключается к календарю или платформе видеозвонков: оно захватывает выбранные источники звука Windows.

## Что потребуется

- Windows 11 x64. Другие ОС не заявлены как поддерживаемые.
- Для голосовых вопросов — модель Whisper Small и подготовленные бинарники; для ручного ввода они не нужны.
- Один из AI-провайдеров: установленный Windows Codex с авторизацией ChatGPT либо доступ к отдельно развёрнутому codex-manager с клиентским токеном.
- Интернет для AI-ответов в обоих режимах. Локальное распознавание аудио работает на компьютере; «локальный Codex» обозначает способ подключения, а не офлайн-модель.

Полный сервер codex-manager не входит в этот репозиторий. Локальный режим позволяет работать без него. Стоимость и доступность AI определяются выбранным провайдером; публикация исходников не предоставляет доступ к сервису или учётной записи автора.

## Запуск для разработки

Нужны Node.js 22.12+ и pnpm 11.19.0. Для компиляции SQLite нужны Visual Studio Build Tools (C++ Desktop) и Python **на машине разработчика**. Пользователю установленного приложения они не нужны.

```powershell
pnpm install --frozen-lockfile
pnpm setup:whisper
pnpm setup:runtime
pnpm run rebuild
pnpm dev
```

`setup:whisper` загружает закрепленный официальный whisper.cpp v1.9.2 и проверяет SHA256. `setup:runtime` сохраняет официальный Microsoft VC++ Runtime с проверкой подписи для включения в установщик; он не устанавливает его на компьютер разработчика. Если Whisper сообщает об отсутствующих DLL, установите этот runtime.

При первом запуске откройте настройки, скачайте Whisper small (~465 MiB) либо импортируйте `ggml-small.bin`. Проверяется точная контрольная сумма multilingual small. Модель прогревается в отдельном CPU-процессе; запись доступна после готовности. Аудио не отправляется за пределы компьютера. Распознанный текст и контекст интервью передаются выбранному AI-провайдеру.

В настройках выберите провайдера AI. Для облачного codex-manager укажите адрес, клиентский токен и профиль `interview-assistant`. Для локального режима нужен установленный Windows Codex с входом ChatGPT; приложение найдёт `codex.exe` автоматически или позволит выбрать файл. Сохраните настройки и проверьте подключение. Начальная модель — `gpt-5.6-sol`, reasoning `low`; каталог поступает из Codex. Режим и модель фиксируются на интервью, изменения применяются к следующему. Локальный режим требует интернета: модель выполняется через Codex, локальными являются CLI и транспорт. Заполните резюме, вакансию и инструкции. Первое нажатие записи или отправка текста создаёт новое интервью; сохранённое можно явно продолжить в истории. Для записи используется `Ctrl+Alt+Space`, для показа/скрытия — `Ctrl+Alt+H`, для пропускания мыши — `Ctrl+Alt+M`. Все сочетания настраиваются. Закрытие оверлея скрывает его; команды «Показать помощника» и «Скрыть помощника» доступны в трее. Двойной щелчок по значку в трее или кнопка «Показать помощника» в настройках восстанавливают окно и управление мышью. Выход из приложения доступен в трее и настройках.

Микрофон и системный звук дают два независимых транскрипта с общими временными метками. Повторное нажатие останавливает запись; через 120 секунд она останавливается автоматически. До трех незавершенных вопросов занимают FIFO-очередь с момента начала записи. Частичный захват требует ручной отправки, пустой звук не отправляется. Можно вводить текст вручную без модели STT.

В разделе «Внешний вид» доступны светлая голубая, тёмная синяя тема и «Полночь». Тема сразу применяется к настройкам, помощнику и истории и сохраняется после перезапуска. По умолчанию выбрана тёмная синяя. Для смены темы нажимать «Сохранить» не требуется; остальные несохранённые настройки сохраняются отдельно.

## Сборка и проверки

```powershell
pnpm typecheck
pnpm test
node --test service-integration/codex-manager/scripts/provision-interview-assistant.test.mjs
pnpm build
pnpm run pack
pnpm run dist
```

Установщик создается в `release/`. Native SQLite собирается для ABI запускающего процесса: после `pack`, `dist` или `pnpm run rebuild` модуль предназначен для Electron. Для возврата к Node/Vitest-тестам хранилища выполните `npm rebuild better-sqlite3`, затем `pnpm test`. Перед запуском приложения снова выполните `pnpm run rebuild`. Остальные unit-тесты не загружают SQLite. Для E2E сначала выполните `pnpm exec playwright install chromium --only-shell`, затем `pnpm build` и `pnpm test:e2e`.

Опциональная проверка реального Whisper на включенных русском и английском аудиофрагментах не использует устройства записи:

```powershell
$env:WHISPER_TEST_BINARY_DIRECTORY = (Resolve-Path resources/whisper).Path
$env:WHISPER_TEST_MODEL_DIRECTORY = 'C:\path\to\model-directory'
pnpm test
```

Без этих переменных native STT тест пропускается. У модели и движка есть собственные проверки SHA256; случайная подмена fixture/runtime не принимается.

Для полного E2E скрытого аудиозахвата задайте `WORK_SEARCH_TEST_MODEL` как абсолютный путь к проверенному `ggml-small.bin` и запустите `pnpm test:e2e`. Chromium получает флаги искусственного микрофона и WAV fixture: физический микрофон не открывается. После `pnpm run pack` команда `pnpm test:packaged` проверяет startup распакованного приложения, защиту окон, шифрование и наличие ресурсов.

## Подготовка сервиса

Скрипты подготовки находятся в `service-integration/` и могут быть аддитивно установлены в codex-manager. [Инструкция](service-integration/README.md) описывает административный предпросмотр, применение и отдельную выдачу клиентского ключа. Модель задается явно и проверяется по актуальному каталогу рабочих процессов. Desktop не принимает административный токен и не использует OpenAI API напрямую.

Текущая подготовка публикует `interview-assistant@2`: постоянный Codex App Server внутри worker передает текст по мере генерации. До публикации профиля нужны обновленные manager и worker с поддержкой этого runtime. В настройках приложения оставьте имя `interview-assistant`, переподключитесь после изменения политики клиента и начните новое интервью. Продолженное сохраненное интервью использует прежнюю серверную конфигурацию. По умолчанию ответ занимает 20–35 слов; инструкции могут явно запросить подробности или код. Первый текст и полный ответ измеряются отдельно; [описание аналитики и замеров](docs/latency.md).

Приложение получает от AI обновления блоков текста, а не гарантированный поток отдельных токенов. Разрыв соединения не означает отмену генерации. Идентификаторы команд и курсор событий сохраняются, чтобы восстановление не запускало второй запрос. Если отмена или доставка не подтверждена, очередь приостанавливается до восстановления соединения. Используйте «Продолжить подключение» в настройках текущего интервью. «Проверить подключение» независимо проверяет сохранённую конфигурацию и не создаёт интервью, не возобновляет очередь и не прерывает активный ответ.

Если сочетание занято другой программой, приложение показывает конкретную ошибку. При запуске остальные свободные сочетания продолжают работать; при изменении настроек прежние сочетания сохраняются, пока все новые не будут успешно зарегистрированы. Ошибка запуска записи по горячей клавише показывает оверлей с объяснением (например, если модель ещё не подготовлена).

## Хранение и границы

- Данные находятся в Electron `userData`: `interviews.sqlite`, `models/`, `diagnostics.log`.
- Токен, профиль, история и содержимое команд в БД шифруются Windows DPAPI через Electron safeStorage. Шифрование защищает от других пользователей Windows, но не от всех процессов той же учетной записи.
- Аудио существует только в RAM. После завершения приложения незавершенное распознавание восстановить нельзя; сохраненный текст и серверные ответы восстанавливаются отдельно.
- История доступна после явного действия «Продолжить». На новой серверной сессии передаются последние 20 завершенных пар в пределах 32 000 символов; остальная история остается локально.
- Удаление истории удаляет записи приложения. Сервис хранит полученные тексты по собственной политике retention. Локальный Codex дополнительно сохраняет интервью в собственной истории; эта копия не удаляется вместе с интервью в приложении и не защищается шифрованием SQLite приложения.
- Диагностика содержит время, этап, код результата, длительность, ID вопроса, провайдера, выбранную локальную модель и версию CLI. Текст, токены и звук в лог не попадают.

Защита окна использует `setContentProtection(true)` до первого показа. Реальный результат зависит от программы и способа захвата; требуется ручная проверка у получателя демонстрации. [Матрица приемки](docs/acceptance.md) отделяет автоматические проверки от проверок на реальных Windows/Zoom/Teams/Meet. Подпись установщика и автоматические обновления в v1 не настроены.

Подробности границ модулей, восстановления и очередей: [архитектура](docs/architecture.md).

Локальный протокол, восстановление и проверка 0.1.4: [docs/local-codex.md](docs/local-codex.md).
